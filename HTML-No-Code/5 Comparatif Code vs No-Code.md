# Projet 5 — Comparatif Code vs No-Code

**Cours :** HTML - No Code  
**Classe :** E1A  
**Niveau :** Avancé  
**Durée :** 1 semaine (PPE)

## Objectif

Construire une même page vitrine avec HTML/CSS et avec un outil No-Code, puis comparer les deux approches selon leur réalisation, leur personnalisation et leur facilité d’utilisation.

## Présentation du projet

Pour ce comparatif, nous avons créé un site vitrine pour **Atelier Lueur**, un atelier de céramique fictif à Lyon. La page présente l’atelier, trois cours et un moyen de contact.

Les deux versions ont le même objectif et présentent les mêmes informations.

## Version Code — HTML/CSS dans Visual Studio Code

La première version a été créée avec HTML et CSS dans Visual Studio Code. Le HTML sert à organiser le contenu de la page. Le CSS sert à définir son apparence : couleurs, espacements et disposition des cartes. Une règle CSS responsive permet d’afficher les cartes les unes sous les autres sur un petit écran.

## Tableau comparatif

| Critère                 | Framer                                                                                                          | HTML/CSS avec Visual Studio Code                                                                           |
| ----------------------- | --------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Profil d’utilisateur    | Plus accessible aux personnes qui ne savent pas coder ou qui sont moins à l’aise avec les outils informatiques. | Convient surtout aux personnes qui connaissent déjà le HTML et le CSS ou qui souhaitent apprendre à coder. |
| Façon de créer la page  | On construit la page visuellement dans l’éditeur et on peut s’aider de l’Agent.                                 | On écrit le contenu en HTML et les styles en CSS.                                                          |
| Modifications           | Les textes et les éléments se modifient visuellement dans l’éditeur.                                            | Il faut modifier le code. Cela donne un contrôle précis, mais demande de comprendre HTML et CSS.           |
| Personnalisation        | La création est rapide, mais certaines personnalisations dépendent des possibilités de Framer.                  | Grande liberté pour ajuster le code et ajouter des styles.                                                 |
| Adaptation au téléphone | Elle se règle dans l’éditeur avec les options de mise en page responsive.                                       | Elle se règle en CSS, par exemple avec une règle `@media`.                                                 |
| Performance             | Non mesurée. Le résultat dépend notamment de la page créée et des ressources chargées par la plateforme.        | Non mesurée. Le résultat dépend notamment du code, des polices et des images chargées.                     |
| Coût                    | Vérifier les tarifs de Framer pour savoir si le domaine et la publication sont compris dans l’offre choisie.    | L’éditeur de code est gratuit. L’hébergement et le nom de domaine peuvent entraîner des frais.             |
| Dépendance              | Le site dépend des fonctions et des conditions de la platefo                                                    | Le site peut être repris par une personne qui sait lire et modifier du HTML/CSS.                           |
## Recommandation

Visual Studio Code, avec HTML et CSS, convient mieux aux personnes qui ont déjà des bases en programmation ou qui veulent apprendre à créer un site en écrivant du code. Cette approche donne davantage de contrôle sur la page, mais les modifications demandent de comprendre les langages utilisés.

Framer convient davantage aux personnes qui ne savent pas coder ou qui veulent créer et modifier un site à l’aide d’un éditeur visuel. Pour un site vitrine simple comme celui d’Atelier Lueur, Framer est un bon choix si le client veut modifier lui-même ses informations facilement.

Je recommande donc Framer à un client qui cherche une solution simple à prendre en main. Je recommande le HTML/CSS dans Visual Studio Code à un client ou à une équipe qui maîtrise le code et souhaite davantage de contrôle sur son site.

## Conclusion

Les deux méthodes permettent de créer une page vitrine présentant le même contenu. Visual Studio Code avec HTML/CSS demande plus de connaissances en programmation, mais offre un contrôle précis. Framer facilite la création visuelle et convient mieux aux personnes qui ne sont pas à l’aise avec le code. Le choix dépend donc du niveau technique du client et de son besoin de personnalisation.
