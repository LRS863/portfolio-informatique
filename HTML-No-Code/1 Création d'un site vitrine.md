# PPE1 – Création d'un site vitrine

## 1. Présentation du projet

L'objectif de ce projet était de créer un site vitrine pour un artisan électricien. Le site permet de présenter les différentes prestations proposées et de faciliter la prise de contact avec les clients.

Le site a été réalisé en HTML et CSS avec Visual Studio Code.

## 2. Livrables

### 2.1 Fichiers du site

Les fichiers réalisés sont :

- `PPE1.html` : contient la structure et le contenu du site.
- `PPE1.css` : contient la mise en forme et le design du site.

## 3. Choix de structure et de conception
**HTML**:
J'ai choisi une structure HTML sémantique afin de rendre le code plus clair et mieux organisé.

Le site est composé de plusieurs parties :

- `<header>` : contient le titre et le menu de navigation.
- `<nav>` : permet de naviguer entre les différentes sections.
- `<main>` : regroupe le contenu principal.
- `<section>` : sépare l'accueil, les services et le contact.
- `<footer>` : contient les informations de bas de page.

**CSS**:
Pour la partie CSS, j'ai choisi des couleurs sobres : le vert foncé, le blanc cassé et le doré. Elles donnent au site une apparence professionnelle.

J'ai également utilisé des blocs interactifs avec les balises `<details>` et `<summary>` pour présenter les services. Chaque prestation peut être ouverte pour afficher sa description et ses photos.

Enfin, j'ai utilisé Flexbox pour organiser les images côte à côte et faciliter leur affichage.
