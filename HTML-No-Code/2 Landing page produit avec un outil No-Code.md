# Projet 2 : Landing page produit avec un outil No-Code

**Classe :** E1A | **Cours :** HTML - No Code | **Date :** 04/11/2026

**Lien de la landing page :** https://planiva-pme.carrd.co

---

## 1. Contexte
Une startup veut tester l'intérêt pour un nouveau produit. Elle utilise une landing page, sans développeur.

## 2. Outil et produit
- **Outil No-Code :** Carrd (plan gratuit).
- **Produit :** Planiva, un logiciel de planification d'équipe pour PME.
- **Remarque :** le produit est fictif.

## 3. Choix marketing
- **Accroche :** Planifiez votre équipe en quelques clics.
- **Sous-titre :** Planiva centralise plannings, congés et absences. Conçu pour les PME.
- **Bénéfices :**
  - Un planning partagé, toujours à jour.
  - Les congés et absences validés en ligne.
  - Moins de temps perdu en administratif.
- **Appel à l'action :** « Demander une démo gratuite ». Le bouton ouvre un email.
- **Message clé :** gagner du temps sur la gestion d'équipe.

## 4. Choix de design
- Fond blanc.
- Bleu foncé pour l'accroche et le bouton.
- Texte noir.
- Une seule police.
- Tout est centré.
- Un seul bouton, pour ne pas disperser le visiteur.

## 7. Avis critique sur le No-Code

**Points forts**
- Rapide : la page a été faite en moins de 1h30.
- Aucun code nécessaire.
- Le rendu est propre.

**Limites rencontrées**
- Un site Carrd = une seule page.
- Le site n'est pas en ligne tant que le compte n'est pas vérifié.
- Un bandeau « Made with Carrd » reste visible en bas de page.
- Pas de formulaire sur le plan gratuit. J'ai utilisé un lien `mailto:`.
- Le lien `mailto:` dépend de l'application email par défaut du visiteur.
- Mon adresse email est lisible dans le code de la page.
- Adresse en `.carrd.co`, sans domaine personnalisé.
- L'export HTML est réservé aux plans payants.
- Je dépends de la plateforme.

**Conclusion**
Le No-Code est adapté pour tester une idée vite. Il devient limité dès qu'il faut plusieurs pages, des formulaires ou plus de contrôle.
